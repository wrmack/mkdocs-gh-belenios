    Managing secrets

    Managing secrets like passwords

    If you sync your local source with a remote repository, for example on Github, you do not want your passwords and other secrets exposed.

    One option is to store passwords in environment variables which are read in to configurations. Scripts storing secrets are added to .gitignore so that they are not pushed to Github whenever you sync. Add the script filenames to .gitignore and commit changes before creating the scripts with the passwords themselves.

    OIDC secrets in ocsigenserver.conf.in

    For example, in the demo directory, ocsigenserver.conf.in could contain the line:

    <auth name="Google"><oidc server="https://accounts.google.com" client_id="_CLIENTID_" client_secret="_CLIENTSECRET_"/></auth>

    Google gives you the clientid and client password when you set up logging in with Google. Store these in a file .env_secrets.sh in the same directory as ocsigenserver.conf.in.

    CLIENTID="<your google clientid>"
CLIENTSECRET="<your google client secret>"

    Amend the demo/run-server.sh script to substitute the environment variables for the placholders here:

    if [ -e .git ]; then
    : ${BELENIOS_CONFIG:=demo/ocsigenserver.conf.in}
    : ${BELENIOS_VARDIR:=_run}
    : ${BELENIOS_RUNDIR:=/tmp/belenios}
    : ${BELENIOS_BINDIR:=_run/usr/bin}
    : ${BELENIOS_SHAREDIR:=_run/usr/share/belenios-server}
    : ${BELENIOS_SECRETS:=demo/.env_secrets.sh}
else
    : ${BELENIOS_CONFIG:=/etc/belenios/ocsigenserver.conf.in}
    : ${BELENIOS_VARDIR:=/var/belenios}
    : ${BELENIOS_RUNDIR:=/run/belenios}
    : ${BELENIOS_BINDIR:=/usr/bin}
    : ${BELENIOS_SHAREDIR:=/usr/share/belenios-server}
    : ${BELENIOS_SECRETS:=/etc/belenios/.env_secrets.sh}
fi
    and here:

    # Load Google clientid and clientsecret from .env_secrets.sh
. $BELENIOS_SECRETS
BELENIOS_CLIENTID=$CLIENTID
BELENIOS_CLIENTSECRET=$CLIENTSECRET

# Substitutions
sed \
    -e "s@_VARDIR_@$BELENIOS_VARDIR@g" \
    -e "s@_RUNDIR_@$BELENIOS_RUNDIR@g" \
    -e "s@_SHAREDIR_@$BELENIOS_SHAREDIR@g" \
    -e "s@_CLIENTID_@$BELENIOS_CLIENTID@g" \
    -e "s@_CLIENTSECRET_@$BELENIOS_CLIENTSECRET@g" \
    $BELENIOS_CONFIG > $BELENIOS_VARDIR/etc/ocsigenserver.conf

    msmtp authentication

    The msmtprc configuration file created by contrib/fedora/make-squashfs.sh requires the AWS SES user and password to be stored in a file .env_secrets_SES.sh in the same directory. That file should have:

    SESUSER="<your AWS SES username>"
SESPASSWORD="<your AWS SES user password>"

    Amend contrib/fedora/make-squashfs.sh:

    # Add this early on in the script
. contrib/fedora/.env_secrets_SES.sh

....

# Use environment variables when configuring msmtp

cat > /etc/msmtprc <<XOF
defaults
tls on
tls_starttls on
tls_trust_file /etc/ssl/certs/ca-certificates.crt
syslog on

account ses
host email-smtp.us-east-1.amazonaws.com
port 587
auth on
user $SESUSER
password $SESPASSWORD
from elections@wrmack.com

account default : ses
# from %U@belenios
syslog LOG_MAIL
XOF
