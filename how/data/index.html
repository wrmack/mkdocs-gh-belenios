    Data storage

    Temporary data

    This is data which does not persist. It includes data which is lost when:

    • the webserver is shut down
    • the user ends their browsing session.

    Persistent data

    Data storage on the server

    This is data which persists on the web server when the server is shut down.

    Type Where* Data
    Admin accounts /var/belenios/accounts as json files id, name, email, last_connected, authentication method, consent date
    Election data** /var/belenios/spool/<uuid> <uuid>.bel, audit_cache.json, dates.json, last_event.json, metadata.json, passwords.csv, records, voters.txt
    Bulk emails /var/belenios/lib/ocsidb as sqlite3 database table xxxx
    Cookies expiry dates /var/belenios/lib/ocsidb as sqlite3 database table xxxx
    Web server logs /var/belenios/log/ access.log, errors.log, warnings.log

    * These paths are from inside a Belenios container. The data is also accessible from outside the container at /srv/belenios-containers/main/belenios/var/...

    ** The spool directory can be configured in ocsigenserver.conf:

        <storage backend="filesystem">
      <uuid length="14"/>
      <spool dir="_run/spool"/>
      <accounts dir="_run/accounts"/>
      <map from="demo_allowlist" to="demo/dummy_logins.txt"/>
      <map from="local_passwords" to="demo/password_db.csv"/>
      <map from="public_passwords" to="_run/password_db.csv"/>
    </storage>

    There is further detail in doc/specification.pdf part 4 "Messages" (the pdf has to be generated from the source code - see INSTALL.md)
